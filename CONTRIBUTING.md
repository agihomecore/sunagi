# CONTRIBUTING · Sunagi
- Каждый коммит — с подписью автора (DCO): `git commit -s` добавляет строку `Signed-off-by`. Ей вы подтверждаете, что имеете право передать этот код под лицензией проекта.
- Лицензия вклада = лицензия той части, куда он идёт (Apache-2.0 или AGPL-3.0; тексты и данные — CC BY 4.0).
- Не присылайте ключи, пароли и личные данные. Перед отправкой проверьте изменения.
- Зависимости с лицензиями GPL/AGPL — только в частях под AGPL. Данные с пометками NC и SA не принимаем.
- Решения по проекту принимает ведущий — ИП SUN. Вопросы — в Issues.
- Общение: по делу и с уважением.
